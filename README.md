# Tower Defense Game

This is a Java Swing tower defense game where the player protects the path by placing different towers and stopping waves of enemies before they reach the end.

## Main Features

- **Start menu** with a simple click-to-play flow.
- **Smooth enemy movement** along the road path.
- **Different enemy types** with balanced stats:
  - Strong enemies have more health but move slower.
  - Fast enemies move quickly but have less health.
  - Medium enemies are balanced between speed and health.
- **Three tower types** with different cost, damage, and attack range.
- **Visible tower range circles** so the player can see how far each tower can attack.
- **Shooting animation** that shows towers firing at enemies.
- **Gold system** for buying towers and earning rewards from defeated enemies.
- **Lives system** where enemies that reach the end damage the player.
- **Wave counter** showing enemy progress.
- **Win and lose screens**:
  - Displays `You Won` after all enemies are defeated.
  - Displays `You Lost` when the player runs out of lives.
- **Background soundtrack** generated in the game to make gameplay less boring.
- **Image fallback support** so the game can still run even if some tile images are missing.
